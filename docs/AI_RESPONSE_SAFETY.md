# AI response-safety guard

## Purpose

PayCheckpoint can display an optional action plan generated by Cloudflare Workers AI after explicit user consent. The model response is untrusted input. Before display, `normalizeModelOutput()` validates its schema and applies a server-side content gate.

## What the deterministic gate currently checks

The validator rejects selected categories of unsafe or unsupported output:

- Instructions to disclose a PIN, OTP, password or verification code.
- Instructions to install or enable known remote-access tools.
- Instructions to pay a recovery, release, verification or processing fee.
- Unsupported claims that a payment/transaction has completed.
- Unsupported reassurance that a payment request is safe, genuine or legitimate.
- Guaranteed refunds/recovery, definitive scam claims, recipient verification claims and unsupported reversal/cancellation claims.

The gate recognizes clear English and Bangla negation so protective warnings remain allowed. For example, “Never share your OTP” is allowed while “Send your OTP to support” is blocked.

## Run the matrix

```bash
npm run qa:ai-safety
```

The 31 developer-authored examples are stored in `evaluation/ai-copilot/response-safety-cases.json`. The runner writes `evaluation/ai-copilot/response-safety-latest.json` with case-level outcomes and a concise pass count. The same runner is part of `npm run qa:release`.

## Evidence boundary

This matrix tests the response validator against selected examples only. It does **not** measure the underlying Qwen3 model's accuracy, factual grounding, output quality, robustness to every prompt injection, or real-world safety. It does not prove every dangerous instruction or hallucination will be detected. Its expected labels are developer-authored, not independently reviewed. Do not present the pass rate as fraud-detection accuracy or model accuracy.

The model still receives only the consented, best-effort-redacted note and categorical context. Redaction is not guaranteed anonymization. The offline plan remains available if hosted AI is unavailable or a response is rejected. Human review and an independently adjudicated bilingual AI-output evaluation remain outstanding.
